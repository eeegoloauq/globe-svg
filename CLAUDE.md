# globe-svg agent notes

Public MIT Node CLI/library for generating static orthographic SVG coverage maps, with optional JSON region paths for site interactivity. Its audience is sites that need a cacheable map without browser mapping code.

- Requires Node 20+. Run `npm ci`, `npm test`, and `npm run examples` to regenerate the committed globe assets. Use `node src/cli.js --config path/to/globe.config.json` for a local config.
- Example generation downloads pinned Natural Earth data on first use and caches it in `~/.cache/globe-svg`; `GLOBE_SVG_CACHE` overrides that location. Tests use a local GeoJSON fixture and need no network.
- Release: bump the package version, run `npm test`, then push a matching `v*` tag. `.github/workflows/publish.yml` runs the tests and publishes to npm through OIDC trusted publishing. There is no site deploy or automated rollback. For a bad package release, deprecate the affected version and publish a corrected version; do not reuse the tag/version.
- Runtime deps stay at d3-geo + the topojson trio.
- Keep the package output static. Browser interaction belongs in integration examples, not in the published runtime. The README's committed `preview.svg` files are separate from the globe assets generated by `npm run examples`.
- Configs can load arbitrary local files or URLs and supply SVG colors; treat configs from untrusted sources as unsafe.
